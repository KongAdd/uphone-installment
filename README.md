# Uphone — ระบบผ่อนมือถือหน้าร้าน

เว็บแอปติดตามสัญญาผ่อนมือถือหน้าร้าน (HTML/CSS/JS ล้วน ไม่ต้อง build)
ข้อมูลสัญญาซิงค์ผ่าน **Google Sheets** (ผ่าน Google Apps Script Web App) เพื่อให้พนักงานหน้าร้านและเจ้าของร้านเห็นข้อมูลชุดเดียวกันจากคนละเครื่อง/เบราว์เซอร์

## โครงสร้างโปรเจกต์

```
uphone-installment/
├── index.html
├── css/style.css
├── js/
│   ├── config.js      ตั้งค่า (อัตราเงินดาวน์/ดอกเบี้ย, Web App URL)
│   ├── calc.js         สูตรคำนวณ/วันที่/สถานะ/สีทั้งหมด (ไม่แตะส่วนนี้)
│   ├── remote.js        fetch เข้า Google Apps Script Web App
│   ├── sync.js          คิวรอ sync + สถานะการเชื่อมต่อ
│   ├── store.js         data layer หลัก (คุยกับ Google Sheets + cache local)
│   ├── seed.js           ข้อมูลตัวอย่าง (ใช้เฉพาะตอนยังไม่ตั้งค่า Google Sheets)
│   ├── view-list.js, view-form.js, view-dashboard.js   หน้าจอ (ไม่ได้แก้เลย์เอาต์)
│   └── app.js             ควบคุมหลัก/นำทาง/ตั้งค่า/sync badge
└── apps-script/
    └── Code.gs           โค้ด backend สำหรับวางใน Google Apps Script
```

## การตั้งค่า Google Sheets Sync

### 1) สร้าง Google Sheet

สร้างสเปรดชีตใหม่ (หรือใช้ของเดิม) — ไม่ต้องสร้างชีต/หัวตารางเอง สคริปต์จะสร้างชีตชื่อ **"สัญญาผ่อน"** พร้อมหัวตารางให้อัตโนมัติในการเรียกครั้งแรก

### 2) วางโค้ด Apps Script

1. ในสเปรดชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ออกทั้งหมด แล้วคัดลอกเนื้อหาทั้งหมดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) ของโปรเจกต์นี้ไปวาง
3. กด 💾 บันทึกโปรเจกต์ (ตั้งชื่อโปรเจกต์อะไรก็ได้ เช่น "Uphone API")

### 3) Deploy เป็น Web App

1. มุมขวาบน กด **Deploy → New deployment**
2. ที่ "Select type" กดไอคอนฟันเฟือง เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** Me (บัญชีของคุณ)
   - **Who has access:** Anyone
4. กด **Deploy**
5. หน้าจอจะขอ **Authorize access** — อนุญาตสิทธิ์ให้สคริปต์เข้าถึงสเปรดชีต (จะมีคำเตือน "Google hasn't verified this app" เพราะเป็นสคริปต์ของคุณเอง กด Advanced → ไปหน้าโปรเจกต์ (unsafe) ได้ตามปกติ)
6. คัดลอก **Web app URL** ที่ได้ (รูปแบบ `https://script.google.com/macros/s/xxxxxxxx/exec`)

> **สำคัญ:** ถ้าแก้โค้ดใน `Code.gs` ภายหลัง ต้องกลับมา **Deploy → Manage deployments → กดไอคอนดินสอ (Edit) → Version: New version → Deploy** เพื่ออัปเดตโค้ดโดย **URL เดิมไม่เปลี่ยน** — ถ้าสร้าง "New deployment" ใหม่แทน จะได้ URL ใหม่และต้องไปตั้งค่าในแอปใหม่ทุกเครื่อง
>
> ถ้าเคย deploy ไปแล้วและมีข้อมูลจริงอยู่ในชีต การอัปเดต `Code.gs` เป็นเวอร์ชันใหม่กว่า **ปลอดภัย ไม่ลบข้อมูลเดิม** — โค้ดจะเติมเฉพาะ "หัวคอลัมน์ใหม่" ที่ยังไม่มีต่อท้ายคอลัมน์เดิมให้อัตโนมัติในการเรียกครั้งถัดไป (ดูฟังก์ชัน `migrateHeaders_`) แถวข้อมูลเดิมไม่ถูกแตะต้องเลย
>
> ตั้งแต่เวอร์ชันที่รองรับอัปโหลด "รูปบัตรประชาชนลูกค้า" สคริปต์ต้องขอสิทธิ์เข้าถึง Google Drive เพิ่ม (เพื่อเซฟรูปลงโฟลเดอร์ "Uphone - รูปบัตรประชาชนลูกค้า") — พอ Deploy เวอร์ชันใหม่ จะมีหน้าต่างขอ Authorize เพิ่มสิทธิ์อีกรอบ กด Authorize ตามปกติได้เลย

### 4) ตั้งค่า URL ในเว็บแอป

1. เปิดเว็บแอป (ดับเบิลคลิก `index.html`)
2. กดไอคอน ⚙️ ที่มุมขวาบน
3. วาง Web App URL ที่คัดลอกมาในช่อง "Google Apps Script Web App URL"
4. กด **ทดสอบการเชื่อมต่อ** เพื่อเช็คว่าเชื่อมได้ (ควรขึ้น "เชื่อมต่อสำเร็จ")
5. กด **บันทึก**

ทำซ้ำขั้นตอนนี้ในทุกเครื่อง/เบราว์เซอร์ที่ต้องการให้เห็นข้อมูลชุดเดียวกัน (วาง URL เดียวกัน)

## หลักการทำงานของระบบ sync (offline-first)

- ทุกครั้งที่โหลดข้อมูลจาก Google Sheets สำเร็จ จะแคชไว้ใน `localStorage` ของเครื่องนั้นด้วย เปิดแอปครั้งต่อไปจะเห็นข้อมูลล่าสุดที่เคยซิงค์ได้ทันที แม้เน็ตช้า/หลุด
- การเพิ่ม/แก้ไข/กรอกยอดชำระ/ลบ จะอัปเดตหน้าจอ + แคชทันที (optimistic update) ไม่ต้องรอเน็ต แล้วค่อยเข้า "คิวรอ sync" (เก็บใน `localStorage` เช่นกัน) เพื่อส่งขึ้น Google Sheets เบื้องหลัง
- เมื่อเน็ตกลับมา (หรือทุก ๆ 20 วินาทีถ้ายังมีคิวค้าง) แอปจะส่งรายการในคิวขึ้นชีตให้อัตโนมัติทีละรายการตามลำดับเวลา โดยไม่ต้องกดอะไรเพิ่ม
- แถบสถานะที่มุมขวาบนบอกสถานะปัจจุบัน:
  - 🟢 **ซิงค์แล้ว** — ข้อมูลตรงกับ Google Sheets ล่าสุด
  - 🟡 **กำลังซิงค์...** — กำลังส่งข้อมูลขึ้น
  - 🔴 **ออฟไลน์ — มี N รายการรอซิงค์** — มีการแก้ไขค้างอยู่ในเครื่องนี้ยังไม่ขึ้นชีต
  - ⚪ **ยังไม่ตั้งค่า Google Sheets** — ยังไม่ได้กรอก Web App URL (ใช้ข้อมูลตัวอย่าง/local เท่านั้น)
- กดไอคอน ⟳ เพื่อสั่งซิงค์ทันทีได้ตลอดเวลา

**ข้อจำกัดที่ควรทราบ:** เลขที่สัญญาใช้เป็นคีย์หลักในการจับคู่แถวกับ Google Sheets จึง **แก้ไขเลขที่สัญญาไม่ได้หลังสร้างแล้ว** (ช่องนี้จะถูกล็อกในหน้าแก้ไข) — ถ้าพิมพ์เลขที่สัญญาผิด ให้ลบสัญญานั้นแล้วสร้างใหม่แทน

## Export / Import (สำรองข้อมูลเพิ่มเติม)

ปุ่ม Export JSON/CSV และ Import JSON ในเมนู ⋮ ยังใช้งานได้ตามปกติ เป็นการสำรองข้อมูลเสริมนอกเหนือจาก Google Sheets — การ Import จะแทนที่ข้อมูลในเครื่องนั้นทั้งหมด และถ้าตั้งค่า Web App URL ไว้แล้วจะพยายามดันข้อมูลที่ import ขึ้น Google Sheets ให้ด้วย (upsert ทีละสัญญา)

## Checklist ทดสอบ

- [ ] เปิดแอปจาก 2 เบราว์เซอร์/2 เครื่อง (ตั้งค่า Web App URL เดียวกันทั้งคู่) กรอกสัญญาใหม่จากเครื่องหนึ่ง แล้ว refresh อีกเครื่อง → เห็นข้อมูลตรงกัน
- [ ] ปิดเน็ต (dev tools → Network → Offline) แล้วกรอกยอดชำระงวด → บันทึกได้ในเครื่อง สถานะ/สี/แดชบอร์ดคำนวณถูกต้องจากข้อมูล local ทันที และ badge ขึ้น 🔴 พร้อมจำนวนรายการค้าง
- [ ] เปิดเน็ตกลับมา → ข้อมูลที่ค้างในคิวขึ้น Google Sheets อัตโนมัติโดยไม่ต้องกดอะไรเพิ่ม และ badge เปลี่ยนเป็น 🟢
- [ ] เปิด Google Sheet ต้นทางตรง ๆ ดูว่าแถวข้อมูลตรงกับที่กรอกในเว็บ
- [ ] สูตรคำนวณ, สีของช่องงวด, สถานะติดตาม ยังทำงานถูกต้องเหมือนก่อนแก้ไข
- [ ] ปุ่ม Export JSON/CSV ยังใช้งานได้ปกติ
